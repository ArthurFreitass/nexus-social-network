Sobre a Nexus

A Nexus é um projeto acadêmico desenvolvido utilizando HTML, CSS e JavaScript. Seu objetivo é simular o funcionamento básico de uma rede social, permitindo cadastro, autenticação de usuários e publicação de conteúdos em um feed.
