# Nexus

Nexus is a simple social network developed using HTML, CSS, and JavaScript.

The project allows users to create an account, log in, and publish posts containing a title, image, and description. Posts are stored locally and remain visible in the feed, even when another user logs into the application.

## Features

* User Registration
* User Login
* Feed with Posts

  * Create posts
  * Add a title
  * Upload an image
  * Write a description
* About page with information about Nexus

## Technologies

* HTML5
* CSS3
* JavaScript
* LocalStorage
